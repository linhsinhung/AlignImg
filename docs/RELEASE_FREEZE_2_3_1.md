# AlignImg 2.3.1 maintenance release

Status (2026-10-07): **T7 installed-artifact server validation accepted;
2.3.1 release artifacts frozen with the recorded T6 exceptions. Not published.**
Core, GPU package and native stamp are `2.3.1`; Workbench stays `0.7.0`.
The historical [2.3.0 release record](RELEASE_FREEZE_2_3.md) is unchanged.

## Scope

- Polar GPU allocation checks minimum feasibility before particle uploads.
- Resident and streaming storage share one batch solver; live Fourier caches,
  fixed arrays, batch scratch and cuFFT reserves share a bounded VRAM budget.
- OOM recovery releases failed allocations, tries streaming/cache eviction,
  and reduces batch size without CPU fallback or repeated M-step accumulation.
- CuPy/native mirror sampling quantizes the original coordinates before periodic
  mirrored index mapping, retaining the existing CPU authority.
- Zero reference-center shift is a true no-op: the original sampling center is
  retained instead of round-tripping through float32 pose values.

Public workflows/config/pose contracts, Fast 3/Balanced/quadratic presets,
requested batch 512 and memory fraction 0.8 remain unchanged. No new search,
classification, precision policy, disk streaming or rescue mechanism is added.

## Accepted compatibility decision

The user explicitly accepted the following narrow exception on 2026-10-07:
the corrected zero-shift controller need not reproduce the old local3050
2.3.0 numerical outputs. Old FAIL reports and dev13's `inconclusive` remain
unchanged; this is an acceptance decision, not a rewritten passing test.

Dev12's controlled A/B established a broad trajectory difference caused by the
controller. Restoring the legacy controller reproduced 3049/3050 poses within
the frozen thresholds; one legacy-only particle remained different. Dev13
passed all six same-input CPU/CUDA comparisons, with exact raw sampling, and
anchored the current endpoint. It did not reconstruct the original B64 legacy
endpoint. Boundary sensitivity was observed, but the complete cause of that
historical endpoint remains unresolved. Diagnosis stops here as agreed.

The earlier user-accepted Xorg observation is separately recorded. Neither
exception waives new resource failures, backend parity, deterministic
same-schedule repeats, mirror/fixed-class contracts or corrected-baseline gates.
Regression baselines are not ground-truth alignment accuracy.
